# `@trogonstack/trogon-eventstore-opentelemetry`

OpenTelemetry instrumentation for `@trogonstack/trogon-eventstore-client`.

```bash
npm install @trogonstack/trogon-eventstore-opentelemetry
```

```ts
import { TrogonEventStoreInstrumentation } from "@trogonstack/trogon-eventstore-opentelemetry";

const instrumentation = new TrogonEventStoreInstrumentation();
```
